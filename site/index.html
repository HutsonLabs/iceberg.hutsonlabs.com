What it holds

Everything connects

Notes

Plain writing with wiki-links and backlinks. Titles come from the first line, raw markup never leaks into the chrome, and the editor keeps a reading measure instead of sprawling across the window.

Journal

A daily page with streaks, reflection prompts, and voice memos. Home widgets keep it one tap away, and every entry is a first-class node in the graph, not a silo.

Graph

Relations are typed — supports, contradicts, cites, causes — and each type carries its own color from a palette validated for color-vision deficiency. The legend chips double as filters.

Capture from anywhere

A share extension and web clipper feed the graph from whatever you're reading; audio memos and scans land as captures. Books, articles, people, places, and events all get their own kind of node — so “where did I read that?” is a link, not a search.

The four meaning-bearing colors
Note Journal Book Capture

Everything else in the app is chrome and one accent. These four encode what a Thing is — on graph nodes, legend chips, and backlink pills — and they are never decorative.

For the agent too

The same graph, both directions
MCP built in

Iceberg ships a server for the Model Context Protocol (MCP), the standard way an agent connects to your tools. So an agent — Claude, in my case — reads and writes the same notes, journal, and relations you do. Ask it what connects two ideas and it answers from your graph; let it file what it learns and you can see exactly where it put things. The server runs on your Mac, where any MCP client can launch it; iPhone and iPad carry the same graph, minus the agent hookup.

What it won't do
  • Require an agent — the notes, journal, and graph are a complete app on their own. Connect an agent when you want one, or never.
  • Take your data — the settings pane says it plainly: nothing here leaves your device today.
  • Trap your notes in a format only it can read.
  • File anything invisibly. The agent's edits land in the same graph you see, where you can follow them.
